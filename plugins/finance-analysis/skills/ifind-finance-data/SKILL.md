# 同花顺金融数据查询 (ifind-finance-data)

- 本技能用于查询股票、基金、宏观经济、行业经济、新闻公告、债券、港美股、指数板块、期货期权、工商企业及法律信息数据指标查询
- 核心特色能力：智能选股选基，金融数据查询，公告资讯搜索，宏观行业指标搜索，工商企业信息查询与企业筛选，司法案例与法条法规检索
- 日内高频实时行情支持：A股/基金/债券/指数（债券仅支持交易所行情，不含银行间）

---

## 数据范围

- **总述**：该服务采用自然语言取数，兼容大量数据指标，以下为范围及样例
- **股票数据**：股票搜索、基本信息、财务数据、行情、股东、风险指标、ESG评级、重大事件等
- **基金数据**：基金搜索、基金资料、基金行情、持仓明细、持有人结构、基金公司信息等
- **债券数据**：债券基本信息、行情数据、财务数据、特殊指标（信用债、可转债、回购等）
- **港美股数据**：港股/美股的智能选股、基本资料、行情数据、财务数据、公告事件等
- **指数板块数据**：指数行情、板块行情、成分股数据等
- **宏观经济数据**：GDP、CPI、PPI、行业经济指标、大宗商品数据等
- **新闻公告**：财经新闻、上市公司公告、热点事件等
- **期货期权数据**：期货期权合约基本资料（合约信息、标的信息）、行情数据（日频行情、技术指标、持仓数据等）
- **工商企业数据**：企业基本信息、股东股权、对外投资、实际控制人/最终受益人、变更记录、年报，经营与司法风险（经营异常、行政处罚、被执行人、失信、限制高消费等），知识产权（商标、专利、软件著作权），经营动态（融资、招聘、招投标等），以及按地区、行业、产业链、资质批量筛选企业
- **法律信息数据**：司法案例检索与裁判文书详情、法条法规检索、法规全文阅读、官方网页搜索与阅读等

## 使用方法

本 skill 封装了同花顺金融数据MCP服务的调用接口，支持 Python 和 Node.js 两种调用方式：
- **Node.js方案**：使用 `call-node.js` 脚本（无需额外依赖，使用内置模块）
- **Python方案**：使用 `call.py` 脚本（需安装 `requests` 库）
- **推荐方案**：当用户未指定python，或不确定python环境时，优先使用Node.js方案
- **query**：股票基金数据查询工具的 query 参数一般支持多主体、多指标，但不宜超过 5 个

## 首次使用

- **验证密钥**: 密钥优先从环境变量 `IFIND_AUTH_TOKEN` 读取；未设置时回退读取 `mcp_config.json` 的 `auth_token` 字段。如不存在有效密钥，需提示用户到 "MCP官网 -> 个人中心 -> 密钥" 路径获取，通过设置环境变量 `IFIND_AUTH_TOKEN` 或替换 mcp_config.json 中的占位符完成配置
- **获取密钥**: 引导用户前往 iFinD MCP 官网 `个人中心-密钥` 界面获取MCP密钥: https://mcp.51ifind.com/#/profile
- **环境验证**: 本技能基于 node.js 环境或 python 环境发起数据查询请求，要求用户至少拥有其中一个，若验证发现均不具备，需提示用户配置环境
- **并发上限**: 免费用户每秒最多并发 2 个请求，个人版正式用户为 5 个，企业版正式用户为 10 个，请注意请求并发量控制；如不确认用户权益，默认为免费版；必要时可向用户询问或引导用户到MCP官网查看权益

## 请求环境

- **请求环境配置**: 为了基于用户所处智能体，提供更好的服务，服务端需要收集当前SKILL执行所处的 `智能体名称(agent_name)`
- 请你在对话上下文中识别收集该名称，并配置到 `skill_env_config.json` 中的 `agent_name` 字段即可
- 该字段值来自 Agent 系统提示词显式声明的名称，如 `claude code` `codex` `workbuddy` `trae` `qoder` 等，若系统提示词未显式声明，则写为空值即可
- *注意*: 只允许收集 **显式声明** 信息，**绝对禁止** 为收集该信息而探测用户本地目录；
- *每次新会话仅配置1次*: 请求脚本会自动读取该字段并作为请求头 `User-Agent` 随所有请求发送，字段为空或配置缺失/读取失败时，该请求头发送空值；故单次会话任务重仅需配置1次

## 使用技巧

- 1.**先搜再查**：针对宏观行业经济指标，当你无法确定用户具体想要的指标，可以先采用 search_edb 进行搜索，然后根据搜索结果指标结合上下文再发起数据查询 get_edb_data
- 2.**查询合并**：股票基金数据查询相关工具支持多主体、多指标，主体数、指标数控制在 5 个以内
- 3.**板块类股票主体**：股票数据查询支持直接以行业板块类股票作为主体，直接查询某行业股票相关数据，但需注意行业范围或时间范围不宜过大，以免触发超长截断
- 4.**有效工具列表获取**: 由于不同权限等级用户的工具清单有差异，当部分工具疑似缺乏权益时，请通过 `list_tools` 或 `listTools` 函数获取当前用户密钥对应的真实有效工具清单
- 5.**高频实时行情**: 当用户数据需求属于 `日内高频分时或实时行情` 数据时，统一加载 `/references/quotes.md`，否则加载对应数据类别所属的参考文档
- 6.**单指标问句补足**: 由于自然语言解析算法受制于 query 复杂度，当多指标问句发现缺失部分指标或失败时，可尝试通过单一指标问句请求来补充
- 7.**工商企业数据两步查询**: 工商企业数据须先通过 `kuaicha_tool_discover` 传入简短中文能力描述检索匹配接口，再依据返回的 `tool_id` 及参数结构调用 `kuaicha_tool_call` 发起查询，详见 `/references/enterprise.md`

## 核心函数

### call(server_type, tool_name, params)

发起金融数据请求。

**参数：**
- `server_type` (str): 服务类型，取值范围：
  - `"stock"` - 股票服务
  - `"fund"` - 基金服务
  - `"edb"` - 宏观经济/行业经济指标服务
  - `"news"` - 新闻公告服务
  - `"bond"` - 债券服务
  - `"global_stock"` - 港美股服务
  - `"index"` - 指数板块服务
  - `"future"` - 期货期权服务
  - `"enterprise"` - 工商企业服务
  - `"law"` - 法律信息服务
- `tool_name` (str): 工具名称，详见 `/references/` 下对应子服务文档
- `params` (dict): 请求参数，不同工具的参数不同

## 注意事项

- 1. 需要有效的 `mcp密钥`（两个方案共用）：优先读环境变量 `IFIND_AUTH_TOKEN`，未设置时读配置文件 `mcp_config.json` 的 `auth_token`
- 2. 请求地址已经内置在请求脚本 call.py 和 call-node.js 内部，密钥也已经在脚本内引用，直接调用即可，无需你重新阅读、生成URL和密钥
- 3. 优先使用Node.js方案（`call-node.js`），无需安装任何依赖，python方案备选
- 4.请求样例中的脚本引用假设临时请求脚本位于SKILL同目录，若实际目录不同，则需注意引用路径问题
- 5. 单次请求完成后，请帮助用户清除你临时生成的取数脚本
- 6. Windows PowerShell 管道执行含中文脚本时，先确保控制台输入输出编码为 UTF-8，避免中文 query 乱码

## list_tools 使用说明

`list_tools(server_type)` 用于获取某个服务当前在线的可用工具列表，但**不应作为首选调用方式**。

### 正确的使用顺序：

1. **优先直接调用**：先按照对应子服务参考文档中工具表所列的 `tool_name` 直接发起 `call()` 请求
2. **异常时备用**：如果遇到以下情况，再尝试调用 `list_tools(server_type)` 获取该服务当前可用的工具清单：
   - 工具调用返回错误，提示工具不存在或名称已变更
   - 不确定某个服务下当前有哪些可用工具
   - 文档中的工具列表与服务端实际提供的不一致
   - 疑似用户缺少工具权益时
3.获取可用工具列表的请求，不会消耗用户权益次数/占用并发限制，在开发请求脚本或面对用户追问时需注意此细节。
