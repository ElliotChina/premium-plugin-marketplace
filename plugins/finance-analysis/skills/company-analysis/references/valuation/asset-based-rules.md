# 资产基础与清算价值规则

资产持有型公司（地产、资源、控股平台）的价值锚在资产本身，而非可持续经营现金流。资产基础价值不新增方法族：重估后的金额经 `sotp` 汇总，按分部口径逐项列示。规则见[估值契约](valuation-contract.md)“公司特征与可执行方法”。

## 调整后 NAV

```
调整后 NAV = Σ 资产重估价值 − 负债 − 表外/或有索偿 − 处置税费
```

- 每项资产单独列为一个 `components` 条目，`value_type` 统一取 `equity`，`component_id` 写资产类别（如 `investment-property-shanghai`），不得把整家公司压成一个组件。
- 负债、少数股东权益、优先索偿、表外担保与或有负债放入 `debt_like_claims`；仅在 `sotp` 案例中作为整体扣减，不重复计入组件。
- 处置税费（土地增值税、资本利得税、交易费用）按资产类别估算后计入 `debt_like_claims` 或直接从组件价值扣减，并在 `rationale` 写明口径。
- method_id 使用 `intrinsic-price-per-share-nav`；`sotp` 的 `nav` 是可选 basis，普通分部加总仍用 `intrinsic-price-per-share`。

## 清算价值

```
清算价值 = 调整后 NAV × (1 − 处置折价) − 清算费用 − 时间折价
```

- 处置折价按资产流动性分档：上市证券与现金接近 0，投资性物业与土地按可变现周期取折价，专用设备与存货取更高折价。
- 清算费用包括法律、审计、遣散与维持运营成本；时间折价按预计变现年限与折现率折算。
- method_id 使用 `intrinsic-price-per-share-nav-liquidation`，同一案例仍按 `sotp` 组件结构填写。
- 清算价值不是股价保底。只有在清算为现实选项（持续经营价值低于清算价值、或治理事件已触发处置程序）时才可作为交叉参考，且须在报告披露这一前提。

## 重估方法

每项资产必须写明重估方法，并引用已核验事实或带锚点的假设：

| 方法 | 适用 | 要求 |
|---|---|---|
| 市价法 | 上市股权、可交易物业、大宗商品库存 | 报价日期、市场与流动性折价 |
| 重置成本法 | 专用设备、基础设施 | 重置单价、成新率与功能性贬值 |
| 收益法 | 出租物业、收费权、资源储量 | 租金/产量、资本化率或折现率、剩余年限 |

不得用账面净资产乘 PB 代替资产重估；PB 只能作为校准工具，不能进入 NAV 组件。资源类资产按可采储量、品位、开采成本与剩余许可年限估值；矿山、收费公路等有明确终止期的资产，持续经营口径应优先使用有限期 DCF，NAV 仅作交叉核对。

## 证据与披露

- 每个组件在 `evidence_fact_ids` 引用重估依据；假设性重估须标记 `fact_type: assumption`，精度降为 `conditional`。
- 报告披露资产重估方法、关键折价与处置税费口径、表外索偿清单，以及清算价值成立的前提条件。
- 同一资产不得同时计入 `components` 与 `non_operating_assets`/`excess_cash`；重复计入在预检阶段拒绝。
