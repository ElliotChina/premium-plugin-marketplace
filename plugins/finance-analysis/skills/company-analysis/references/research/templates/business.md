# 业务与护城河研究交付模板（02–03 章）

本模板规定业务与护城河研究员的交付结构。指标定义与公式以各章方法为准，模板只固定报告结构、表格列与必查行；行按公司实际填写，经济上不适用的行注明理由。

## 交付物

一份 Markdown 报告，run 内写入分派提示指定的 run 路径（约定 `runs/<run-id>/analysis/research-business.md`）；独立调用时写入调用方指定路径，未指定时写当前工作目录 `research-business.md`。run 内报告供协调者组装 15 章终稿、冻结评分与估值输入；不提交最终分数或目标价。

## 前置输入

run 内开始前读取行业与同业研究员的同业池与比较口径、财务与现金流研究员的盈利核对结论，同业对照直接引用其同业池，不另选同业；独立调用时无前序底稿，同业按 04 章方法自行选择并注明依据。

## 报告结构

1. **方向总览与阶段判断**：02–03 各章一句结论，注明主要依据与置信度（高/中/低）。
2. **分章分析**：每章一节，小节按该章方法的核心问题、计算与分析、例外与反证组织，标题按实际研究问题命名。
3. **核心指标表**，列固定为 `指标｜口径｜公司值｜基准或同业｜期间｜来源编号｜备注`。必查行：
   - 02 章：分部收入结构与占比、销量 × 单价分解、留存率或复购率、单位经济性、经常性收入占比；劳动或研发密集业务加人均营收、人均利润。
   - 03 章：市场份额、相对份额、毛利率与同业中位数差值、前五大客户收入占比、留存或续约率。
4. **方向专属表格**：见下节。
5. **反证与例外**：每项关键判断的最强反例及其边界。
6. **缺口清单**：`编号｜缺口｜受影响判断｜已查范围｜补齐条件`，编号与 run 检查表一致。
7. **评分与估值输入提示**：列出直接支持各评分维度或估值参数的已核验事实，每条附值、单位、币种、期间、口径与来源定位，对齐[共用事实字段](../../scoring/scoring-contract.md#共用事实字段)。

## 写作要求

结论解释机制与证据；趋势判断至少两个可比期间支持，不使用固定档位词表。每个关键数字给出口径、期间与来源编号；未披露的经营指标不反推为公司事实。02 章增长驱动分解至少三项、其中两项覆盖两个及以上可比期间；03 章护城河对照至少两家可比公司。同业对照 run 内引用行业与同业研究员的同业池，独立调用时按 04 章方法自行选择；均注明统计范围与可比性限制。
