# 资本配置与股东研究交付模板（09–10 章）

本模板规定资本配置与股东研究员的交付结构。指标定义与公式以各章方法为准，模板只固定报告结构、表格列与必查行；行按公司实际填写，经济上不适用的行注明理由。

## 交付物

一份 Markdown 报告，run 内写入分派提示指定的 run 路径（约定 `runs/<run-id>/analysis/research-capital.md`）；独立调用时写入调用方指定路径，未指定时写当前工作目录 `research-capital.md`。run 内报告供协调者组装 15 章终稿、冻结评分与估值输入；不提交最终分数、目标价或仓位建议。

## 前置输入

run 内开始前读取财务与现金流研究员的盈利与现金流底稿，分红、回购与资本开支的可持续性判断与其现金流事实同口径；独立调用时无前序底稿，先核验可用财务事实再分析。

## 报告结构

1. **方向总览与阶段判断**：09–10 各章一句结论，注明主要依据与置信度（高/中/低）。
2. **分章分析**：每章一节，小节按该章方法的核心问题、计算与分析、例外与反证组织，标题按实际研究问题命名。
3. **核心指标表**，列固定为 `指标｜口径｜公司值｜基准或同业｜期间｜来源编号｜备注`。必查行：
   - 09 章：ROIC、增量 ROIC、主要资本用途及已核验回报、并购商誉与承诺兑现、回购/增发每股影响、分红 FCF 覆盖、关联交易、审计意见类型。
   - 10 章：股息率、股东收益率、股息率利差、分红率与现金流分红率（含三年/五年均值）、股息 CAGR 与连续增长记录、前十大集中度、人均持股数与金额、内部人净买入。
4. **方向专属表格**：见下节。
5. **反证与例外**：每项关键判断的最强反例及其边界。
6. **缺口清单**：`编号｜缺口｜受影响判断｜已查范围｜补齐条件`，编号与 run 检查表一致。
7. **评分与估值输入提示**：列出直接支持各评分维度或估值参数的已核验事实，每条附值、单位、币种、期间、口径与来源定位，对齐[共用事实字段](../../scoring/scoring-contract.md#共用事实字段)。

## 写作要求

结论解释机制与证据；事件区分已发生、计划与推断并标注日期与状态，不使用固定档位词表。每个关键数字给出口径、期间与来源编号；未经核验的线索与已核验事实分开。不同市场的披露差异按各章方法的例外条款处理并说明限制。
