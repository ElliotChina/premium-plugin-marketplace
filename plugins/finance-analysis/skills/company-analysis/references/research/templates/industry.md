# 行业与同业研究交付模板（04 章）

本模板规定行业与同业研究员的交付结构。指标定义与公式以各章方法为准，模板只固定报告结构、表格列与必查行；行按公司实际填写，经济上不适用的行注明理由。

## 交付物

一份 Markdown 报告，run 内写入分派提示指定的 run 路径（约定 `runs/<run-id>/analysis/research-industry.md`）；独立调用时写入调用方指定路径，未指定时写当前工作目录 `research-industry.md`。run 内报告供协调者组装 15 章终稿、冻结评分与估值输入；不提交最终分数或目标价。同业池与比较口径单列成节，供业务与护城河研究员对照和估值选择可比公司复用。

## 报告结构

1. **方向总览与阶段判断**：04 章一句结论，注明主要依据与置信度（高/中/低）。
2. **分章分析**：按该章方法的核心问题、计算与分析、例外与反证组织小节，标题按实际研究问题命名，覆盖赛道定义、供需与新供给、景气指标及最强反证。
3. **核心指标表**，列固定为 `指标｜口径｜公司值｜基准或同业｜期间｜来源编号｜备注`。必查行：行业增速与 CAGR、渗透率、CR3/CR5/CR10、HHI、产能利用率、相对增长，行业价格或组合增幅（多个可比期间）、净新增产能相对需求增量、已颁布政策对需求与利润的量化影响、监管与合规成本占比，以及至少三项适用景气指标。
4. **方向专属表格**：见下节。
5. **反证与例外**：每项关键判断的最强反例及其边界。
6. **缺口清单**：`编号｜缺口｜受影响判断｜已查范围｜补齐条件`，编号与 run 检查表一致。
7. **评分与估值输入提示**：列出直接支持各评分维度或估值参数的已核验事实，每条附值、单位、币种、期间、口径与来源定位，对齐[共用事实字段](../../scoring/scoring-contract.md#共用事实字段)。

## 写作要求

结论解释机制与证据；趋势判断至少两个可比期间支持，不使用固定档位词表。每个关键数字给出口径、期间与来源编号；行业数据与公司事实分开标注身份，中位数、区间和排名可由采用的原始数据复算。同业数据注明统计范围与可比性限制。
