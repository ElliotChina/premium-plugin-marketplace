# 财务与现金流研究交付模板（05–08 章）

本模板规定财务与现金流研究员的交付结构。指标定义与公式以各章方法为准，模板只固定报告结构、表格列与必查行；行按公司实际填写，经济上不适用的行注明理由。

## 交付物

一份 Markdown 报告，run 内写入分派提示指定的 run 路径（约定 `runs/<run-id>/analysis/research-financial.md`）；独立调用时写入调用方指定路径，未指定时写当前工作目录 `research-financial.md`。run 内报告供协调者组装 15 章终稿、冻结评分与估值输入；不提交最终分数或目标价。五年财务与现金流底稿同时供业务与护城河、资本配置与股东、风险与反证研究员复用。

## 报告结构

1. **方向总览与阶段判断**：05–08 各章一句结论，注明主要依据与置信度（高/中/低）。
2. **分章分析**：每章一节，小节按该章方法的核心问题、计算与分析、例外与反证组织，标题按实际研究问题命名。
3. **核心指标表**，列固定为 `指标｜口径｜公司值｜基准或同业｜期间｜来源编号｜备注`。必查行：
   - 05 章：营收、归母净利润、归母净资产、市值四项五年 CAGR；总量与每股增长对照。
   - 06 章：毛利率、营业利润率、净利率、期间费用率、ROE、ROA、非经常损益占比、营业利润占税前利润比重；EBIT 与 EBITDA 金额（注明与营业利润、折旧摊销的勾稽）。
   - 07 章：资产负债率、速动比率、现金覆盖有息负债、净债务/EBITDA、利息覆盖倍数、应收/年营收、商誉敞口、应收/存货/应付天数、现金转换周期。
   - 08 章：销售收现率、年度净现比、三年累计净现比、应计比率、资本开支强度、FCF 利润含量。
4. **方向专属表格**：见下节。
5. **反证与例外**：每项关键判断的最强反例及其边界。
6. **缺口清单**：`编号｜缺口｜受影响判断｜已查范围｜补齐条件`，编号与 run 检查表一致。
7. **评分与估值输入提示**：列出直接支持各评分维度或估值参数的已核验事实，每条附值、单位、币种、期间、口径与来源定位，对齐[共用事实字段](../../scoring/scoring-contract.md#共用事实字段)。

## 写作要求

结论解释机制与证据；趋势判断至少两个可比期间支持，不使用固定档位词表。每个关键数字给出公式代入、单位与来源编号；无法核实的数字标为线索或假设，不混入已核验事实。财务历史按[财务历史与可比性](../methods/common-metrics.md#财务历史与可比性)执行；金融机构及早期/未盈利、控股平台、授权、券商资管等特殊类型按[行业适配](../methods/common-metrics.md#行业适配)调整必查行并注明替代口径。
