# 风险与反证研究交付模板（11 章）

本模板规定风险与反证研究员的交付结构。指标定义与公式以各章方法为准，模板只固定报告结构、表格列与必查行；行按公司实际填写，经济上不适用的行注明理由。

## 交付物

一份 Markdown 报告，run 内写入分派提示指定的 run 路径（约定 `runs/<run-id>/analysis/research-risk.md`）；独立调用时写入调用方指定路径，未指定时写当前工作目录 `research-risk.md`。run 内报告供协调者组装 15 章终稿、冻结评分与估值输入；不提交最终分数、目标价或仓位建议。

## 前置输入

run 内开始前读取行业与同业、财务与现金流、业务与护城河、资本配置与股东四份方向报告，风险传导与反证围绕其关键判断展开，不重复各方向分析；独立调用时以待反证的结论及其支撑资料为对象。

## 报告结构

1. **方向总览与阶段判断**：11 章一句结论，注明主要依据与置信度（高/中/低）。
2. **分章分析**：按该章方法的核心问题、计算与分析、例外与反证组织小节，标题按实际研究问题命名。
3. **核心指标表**，列固定为 `指标｜口径｜公司值｜基准或同业｜期间｜来源编号｜备注`。必查行：三至五项核心风险及下行情景量化、每项核心判断的反证指标。
4. **方向专属表格**：见下节。
5. **反证与例外**：每项关键判断的最强反例及其边界。
6. **缺口清单**：`编号｜缺口｜受影响判断｜已查范围｜补齐条件`，编号与 run 检查表一致。
7. **评分与估值输入提示**：列出直接支持各评分维度或估值参数的已核验事实，每条附值、单位、币种、期间、口径与来源定位，对齐[共用事实字段](../../scoring/scoring-contract.md#共用事实字段)。

## 写作要求

结论解释机制与证据；每项风险有专项证据、财务传导和明确改判条件，不使用固定档位词表。每个关键数字给出口径、期间与来源编号；未核验主张与已核验事实分开；需补证或修正的事项在冻结前（独立调用时在结论采信前）交回协调者或调用方。
