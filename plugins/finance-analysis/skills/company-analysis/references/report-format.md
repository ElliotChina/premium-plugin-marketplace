# Markdown 报告的阅读结构

按 `01–15 章 → 覆盖率核对 → 来源清单` 排列。标题使用 `## 05 五年成长质量` 形式：保留两位编号、顺序和该章主题，具体标题可按公司问题改写，不在标题中写 `[5/15]`。每章开头写 `状态：已完成 / 结论受限 / 不适用` 中的一个。章内小标题应按实际研究问题命名，不能机械重复“关键数据与来源、计算与比较、解释与阶段结论”四格。

## 章节顺序

`01 独立结论轴、估值与监控 → 02 业务模式质量与增长引擎 → 03 护城河与竞争地位 → 04 行业质量、前景、景气度与同业 → 05 五年成长质量 → 06 利润表与盈利能力 → 07 资产负债表与营运资本 → 08 现金流与利润含金量 → 09 资本配置与治理 → 10 分红、股东结构与增减持 → 11 风险、周期与反证 → 12 估值方法选择 → 13 三情景估值指标区间 → 14 动态交叉验证 → 15 分析范围与数据说明 → 覆盖率核对 → 来源清单`。

01 结论章开门见山，章首三句各答一问：第一句公司质量如何——总体评分走向与最大支撑；第二句当前价格值不值——相对中性估值区间的位置；第三句最怕什么——最可能推翻结论的一件事。三句之后依次展开估值位置、各独立判断轴、核心分歧与触发器，再进入论证。评分与估值保持独立，不把多轴分数平均。01 与 15 章由协调者编写——01 章在评分与估值完成后最后写；15 章声明研究范围与资料口径，输入冻结时即可定稿。02–11 章依据[逐章研究方法](../SKILL.md#分析方法)，仍按行业与同业、财务与现金流、业务与护城河、资本配置与股东、风险与反证五个方向交接；12–14 章依据[估值契约](valuation/valuation-contract.md)。

## 章内展示

| 模块 | 适合的章内组织方式 |
|---|---|
| 01 结论 | 章首三句（质量/估值/风险）；估值位置与判读；各独立判断轴；核心分歧与裁决；触发器表。 |
| 02–03 业务与护城河 | 收入或优势机制；公司证据与竞争对照；失效条件和判断。 |
| 04 行业与同业 | 赛道供需与景气；可比公司表；差异和阶段判断。 |
| 05–08 成长与报表 | 历史趋势；关键项目和比率；驱动与勾稽；质量与持续性。 |
| 09–10 资本与股东 | 再投资、分红、回购及持股变化；治理与股东回报。 |
| 11 风险 | 情景矩阵；量化影响；整体风险等级（重大／较高／关注／一般＋一句依据）；预警及反证条件。 |
| 12–14 估值 | 方法取舍；三情景假设和结果；反向估值与敏感性。 |
| 15 范围 | 研究对象与期间；资料口径及其对后续计算的影响。可简短。 |

## 研报级展示规则

每章按"结论 → 数据 → 论证"排列，读者只读各章第一块即可串起全报告结论：

1. **结论先行。** 状态行下一行起用 `**本章结论：**` 加粗段写 1–3 句判断，句中嵌关键数字（比率、区间、与基准的差异）；先裁决后理由，不写"我们认为""值得注意的是"等填充语。02–14 章的结论不得与 01 章三句及各判断轴矛盾；发现矛盾时先回改研究记录再写报告。
2. **数据进表，正文留判读。** 逐年序列、同业对比、结构拆分、情景与敏感性一律用表呈现，正文不再复述表内数字，只写表格看不出的判读——驱动因素、同口径差异、持续性与推翻条件。派生数的公式与代入数放表格脚注或相邻一行，保证可复算（勾稽要求不变）。
3. **表格为图表而生。** 一表一主题，列名规范、带单位和期间，短来源编号标注在表题或行内：
   - 时间序列表：期间为行、按升序，指标为列——直接转折线图；
   - 同业对比表：一行一公司，基准公司放首行或末行——转条形图或雷达图；
   - 结构拆分表：构成项为行，金额、占比、同比为列——转堆叠图；
   - 情景区间表：情景为行，指标区间与价格区间为列，价格区间首尾衔接——转区间图；
   - 敏感性表：两参数为行列的矩阵——转热力图；
   - 评分轴表：轴为行，轴分、档位、证据状态为列——转条形图。
4. **覆盖完整但不注水。** 每章覆盖方法文件与核心覆盖表的全部分析点；一个分析点一行证据或一行表，不重复展开。缺数据时在该章用一行说明已查来源、替代依据与结论影响并沿用缺口编号，不为凑篇幅改写研究过程。

完整样例见[报告样例](report-example.md)（虚构公司，仅示范格式与信息密度）。

通用要求不变：事实带期间、数值、单位、口径和短来源编号；数量分析保留公式、代入数和同口径基准；定性分析展示机制、公司证据、对照与反例；阶段判断解释持续性和推翻条件。内容多时增加行和小节，不能删去关键取数与解释。图表只在趋势、结构或同业差异需要视觉呈现且可由已有数据直接生成时使用；Markdown 没有图表配额。



写作时逐项对照 `analysis/research.md` 的核心指标覆盖表。一个指标有值就在相应章节展示计算或比较；缺数据时在该章说明已查来源、替代依据与结论影响，并沿用缺口编号；经济上不适用时说明原因。正文中每个关键派生数值与研究检查表的勾稽行核对期间、单位、代入数和结果；总收入、持续经营收入与终止经营收入等可相加项目必须彼此一致。内容多时增加行或小节，不省略指标。

`结论受限` 的章节在章末放 `### 缺口与影响` 表，一个独立事实缺口占一行，沿用研究检查表编号：

| 编号 | 缺口 | 受影响的分析 | 已核验事实与替代检查 | 对结论的影响 | 补齐条件 |
|---|---|---|---|---|---|

同一缺口影响多章时复用同一编号，每章只写本章的具体影响。无法补齐或记录仍不完整时如实说明，不能把猜测写成披露事实。`已完成` 不放空缺口表；整个模块无经济意义才标 `不适用` 并说明替代检查。

估值位置紧跟章首三句展开：引用主方法中性估值区间（`check` 强制正文含其下界与上界），并紧跟一句当前位置判读——价格落在区间哪一段、离保守或乐观边界多远；价格在区间外时明确写"高于/低于整个区间"并指出市场隐含的方向，不留在区间内外的含糊表述。缺股价时给价值区间并标明当前位置暂不可判定。

第 1 章用一张紧凑的 `核心分歧与裁决` 表呈现最影响公司质量或估值的 1–3 个争议；没有实质争议时，展示最强反证及其为何未改变判断，不编造对立观点。每行包含 `议题｜支持证据｜反对证据或替代解释｜裁决及理由｜改判条件`；改判条件只写一句话并指向触发器表编号，不在此展开。证据带来源编号，估值影响引用已完成的情景或敏感性结果。此前章节尚未展开时，用交叉引用指向后文章节，不在本章重写一轮长篇辩论。01 章末尾放一张 `触发器表`（3–5 行）集中全章更新规则，每行为 `信号｜可观察阈值｜推翻哪条结论`；各判断轴与分歧表涉及改判处都指向它，不在章内多处重复。最终结论审视还要核对评分与估值评审（含估值批判与修订）的完成状态、确定性分数与敏感性区间、反证、缺口、风险状态和正文措辞；把审视与修订记入 `analysis/research.md`。审视发现新的实质事实错误时按冻结规则另建 run，报告措辞或引用错误在本 run 修正。

报告最后列 `已完成：X；结论受限：Y；不适用：Z` 与实际完成率 `X ÷ (15 − Z)`；来源清单逐项列出来源编号、文件名、发布方、日期、链接和具体定位。正文关键事实用 `[S…]` 引用 `add-source` 返回的原编号；多来源可写 `[S1、S2]`，范围引用逐项展开。来源清单使用同一编号；原件失效的旧编号标明“未核验线索”，在相应缺口表说明对结论的影响，不以该编号支持已核验结论。审计哈希留在 `sources.json` 中。

逐章复核数值、公式代入、期间与币种、同业可比性、推断与假设、核心指标覆盖、缺口状态及反证条件。报告用于研究，不构成个性化投资建议；不得有“待填写”占位符或凭证。最终发布及机器检查按[研究流程](research-workflow.md#报告交付)执行，机器检查不能代替实质复核。
