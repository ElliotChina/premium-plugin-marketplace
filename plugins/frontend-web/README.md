# frontend-web

Web 前端界面技能插件。

## 技能

### web-design-guidelines

Web 界面设计审查技能（源自 [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)）：按 Web Interface Guidelines 审查 UI 代码，覆盖可访问性、设计与用户体验最佳实践。

```bash
/web-design-guidelines   # 审查当前改动的 UI 代码
```

### frontend-ui-engineering（源自 [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)，MIT）

前端工程技能：构建生产级、可访问、响应式的用户界面。覆盖组件实现、布局、WCAG 可访问性要求、状态管理等，输出避免"AI 生成感"。详细可访问性要求见 `references/accessibility-checklist.md`（160 项检查清单，由技能按需引用）。

## 安装

```bash
claude plugin install frontend-web@premium-plugin-marketplace
```
